# VISO (viso.ai)

> viso.ai builds Visual General Intelligence — computer vision that understands any scene out of the box without data collection, annotation, or per-question retraining. Its two products are Viso Suite, a no-code/low-code end-to-end platform to build, deploy, scale, and operate real-world computer vision applications, and Viso Now, an agentic computer vision platform whose vision agents connect a camera feed, recognize the scene, write detection logic, and wire alerts automatically. Viso Now plugs into existing cameras and video systems via ready-made connectors and pushes outputs to Slack, Teams, email, or any downstream system over a direct API.

## API

- [Viso Now Docs](https://docs.now.viso.ai/): documentation for the Viso Now product and API
- Viso Now GraphQL API: `https://now.viso.ai/api/svc-viso-now/graphql` (Apollo Server; authenticated, introspection disabled)
- Viso Now Notifications GraphQL API: `https://now.viso.ai/api/svc-viso-now-notifications/graphql`
- Authentication: Google Identity Services (OAuth 2.0 / OIDC) sign-in plus a session credential; anonymous access is denied (HTTP 403)
